# SHORTS FACTORY

縦型ショート動画・自動生成システム風のダッシュボード(1ファイル完結のWebアプリ)。

黒×琥珀色のターミナル調UIで、以下のワークフローを再現しています。

**01 入力 → 02 構成 → 03 生成 → 04 候補**

## 機能

- **RESEARCH パネル** — 架空の件数・フック型・走査ログを表示するシミュレーション。実動画は取得しません
- **GENERATOR** — 商品ページのURLを入力して「生成開始」を押すと、縦型ショート用の台本を3タイプ同時生成
  - A 問題提起型
  - B ビフォーアフター型
  - C ランキング型
- **バリエーション生成** — フック・展開・CTAを複数パターンからランダム選択。各カードの「↻ 再生成」で1本ずつ作り直し可能
- **ジャンル自動判定** — URL・商品名から美容/ガジェット/健康/グルメを判定し、台本の語彙を切り替え
- **商品情報の手動入力** — 商品名・特徴を任意入力でき、台本に反映(URL推定より優先)
- **投稿候補時刻の自動計算** — 現在時刻から次のゴールデンタイム(7時/12時/19時/21時)を3枠表示。予約登録や実投稿は行いません
- **履歴** — 生成結果を直近10件までlocalStorageに保存し、HISTORYから復元
- **一括コピー** — 3本まとめて/1本ずつクリップボードにコピー
- **Claude API連携(任意)** — 「API ⚙」からAPIキーを設定すると コードに指定した `claude-sonnet-5` で API 台本生成を試みる。モデルの提供状況と実接続は未確認(未設定・失敗時はテンプレートにフォールバック)
- JST時計・ステータスバー・CRT風スキャンライン演出、モバイル対応(RESEARCHパネルは折りたたみ)

## 使い方

`index.html` をブラウザで開くだけです。ビルド・依存関係・APIキーは不要。

```
open index.html
```

GitHub Pages を有効化すれば、そのままWebで公開できます。

## 注意

- RESEARCH パネルの走査ログ・件数は**デモ用のシミュレーション**です(実際にYouTube/TikTok APIへはアクセスしません)
- 商品ページ本文は取得しません。API 未設定時は URL・入力名・特徴に基づくテンプレート生成です。API 設定時も渡すのは入力 URL・商品名・特徴であり、商品事実の検証を保証しません
- API キーは現在のページのメモリにのみ保持します。API 利用には外部送信と利用料が発生し得ます。キーや実データを使った接続確認は行っていません
- 生成結果は確認用の下書きです。価格・効能・実績・ランキング・広告表現を出典に照らして人が確認してから使ってください

## 検証

`node --test test/*.test.cjs` で API キーの非永続化とデモ表示の契約を確認します。実 API・SNS 投稿・商品情報の正確性はこの検査の対象外です。
